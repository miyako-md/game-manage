# 公告与资讯

四个游戏统一使用“公告与资讯”列表。按文章内容选择一个主分类，仅显示有内容的分类；混合版本说明可以附带卡池、签到、奖励等标签，未知主题归入“其他”。分类规则集中在 `frontend/src/articles.js`，可以扩充而无需改采集或存储接口。

一级列表展示标题、节选、日期、来源和原链接。点击标题或“查看详情”显示正文、可用图片及全部原链接；关闭后保留列表筛选。详情以纯文本渲染，来源 HTML 中的脚本、样式和嵌入内容不执行。

- 英雄联盟：现有官网公告及综合资讯合并，文字正文取官方 CMC 详情接口。视频和外部专题跳转保留原链接并提示前往原文。
- 鸣潮：现有库街区公告列表逐篇读取既有帖子详情接口。
- 异环：保留塔吉多官方栏目返回的正文，并与现有 B站官方动态合并。
- 终末地：官网公告、活动和新闻逐篇读取官网详情，资讯缓存与日历解析成功状态独立。
- B站：游戏内通知继续采用原决策；网页活动、创作征集、同人征集和线下活动等官方图文社区资讯单独纳入展示，保持原 `decision`，不加入日历或提醒。视频、PV、实机展示等保持过滤。

单篇正文失败保留标题与原链接；有旧完整正文时保留并标明旧正文。正文缺失或截断明确提示，不用摘要冒充全文。历史社区记录缺少完整性信息时保守提示未验证；下一次正常采集记录内容状态，无须数据库迁移或强制历史回补。

同原链接合并；不同来源的同主题同日文章合并时保留所有原链接及可用正文。同一来源的不同文章和不同发布日期保留。正文选择参考完整性和抓取时间，更新成功的正文可以替换旧缓存。

回归覆盖四游戏入口、分类与混合标签、正文详情和关闭、原链接、异常隔离、旧正文保留、重复合并、社区资讯与日历隔离，以及原 B站登录功能。真实界面验证仅进行只读访问，不触发登录或短信。
