## 数据与展示边界

- 文字摘要和完整长图来自同一显示文档。图片不可用、超限或发送前上传失败时文字回退并明确是摘要；消息发送结果不确定时沿用原幂等保护，不重复补发。
- 卡片共用本地看板的深灰色、游戏主题色和中文字体层级，角色使用头像网格，详情包含角色、武器、技能、装备图标与属性分区，真实资源比例使用进度条。终末地使用专属直角工业框、编号章节与黄青强调，复用官网 35 张头像及 35 张人物图；详情人物图失败回退小头像，缺图行紧凑排列。鸣潮/异环沿用既有公开素材目录，独立公共缓存无账号认证；游戏几何徽标为本项目原创，并非官方美术。来源和安全边界见 [公开图标](qq-public-assets.md)。
- 查询只读已有缓存，刷新指令才显式提交已有能力队列。未知、未采集、失败保留旧数据、历史不完整分别说明。v2正常长列表完整绘制，不再六条分页；达到文档/像素/体积边界明确提示，不能把省略内容当完整。所有时间按北京时间显示到分钟，日期本身只有日精度时不编造时间。
- 鸣潮抽卡读取已存在的本人作用域账本，未导入时提示网站操作。鸣潮详细属性/技能/声骸读取最近100条本人详情观测中的精确角色匹配；未命中说明详情未采集或不在近期缓存，需在网站查看角色后再查，不从QQ发起上游详情请求。
- 异环角色/武器/技能来自现有角色缓存，官方配队只呈现来源资料，不自动生成推荐。资源报表是期间获取量，不冒充钱包余额。
- 终末地鹰角寻访与森空岛档案分区显示，禁止合并不同身份。森空岛的干员、装备、理智、地区、帝江号、光荣之路等从其已有账号快照投影；无该授权时给出所需授权提示。`终末地 光荣之路`、`终末地 勋章` 和 `终末地 奖章` 等价，列表完整显示已返回勋章，未知等级/镀层不猜测。本地登录/档案已有单账号实测记录，本期 QQ 八图仅使用合成账号验证，尚未据此宣称真实送达。
- 终末地角色详情复用网页“查看配装”取得的内存缓存，严格匹配账号、角色、授权 ID/版本及干员 ID；未命中时提示在网页查看，服务重启后需重新取得。基础练度与独立配装分别标记时间，旧详情和失败保留状态明确显示。QQ 查询不加载凭据、不触发详情抓取。
- 帝江号以黄/青状态条显示心情、信赖快照百分比和信赖阶段，保留原始值并注明公开模型来源；缺失或超范围的心情保持未知，不外推当前状态。角色详情补充已观测战术道具及主动/被动效果，缺失不代表未装备。光荣之路按来源分类整理，分类统计先于明细，逐类注明本图与已采集数量；缺分类的勋章仍保留。
- `终末地 挑战` 读取同一森空岛授权、角色与授权版本下的战争/丰碑/危机默认查询内存缓存；各自显示抓取时间，未查看时提示先在网站打开分类，重启后需重新取得。失败保留原观测时间并标记旧值；默认查询未命中时不拿单赛季或特定记录缓存替代。空列表和未知成绩不推断为未挑战，也不宣称全部历史。只读路径不创建 runtime、不重新加载凭据、不发起上游请求。
- 挑战长图先展示三分类状态与独立时间，再为各类分配明细；大量战争周次不会挤掉丰碑与危机摘要。各类分别列出赛季、周次、关卡组、荣誉或记录的“本图 / 已观测”数量，超限省略明确说明，文字回退也优先保留三类摘要。
- `终末地 寻访战报` 先列各池统计、成功扫描时间和已保存记录范围，再均衡安排6★明细。每池说明“本图 / 报告 / 账本”的数量，报告最近50条的限制与图片预算限制分别显示；四星和其他/未知分开，均抽来自报告准确区间，不因图片裁减而变化。文字回退优先各池统计，超过可容纳池数时说明省略。最近查询失败与账本成功扫描时间分别保留，不把历史账本时间当成本次成功。
- 显示数据以明确字段投影，不输出原始上游载荷或凭据；UID脱敏。综合图片缓存包含全部账号/角色/授权版本/快照指纹，渲染后再检查QQ绑定及全部授权。
