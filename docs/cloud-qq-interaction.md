## 数据与展示边界

- 文字摘要和完整长图来自同一显示文档。图片不可用、超限或发送前上传失败时文字回退并明确是摘要；消息发送结果不确定时沿用原幂等保护，不重复补发。
- v2共用本地看板的深灰色、游戏主题色和中文字体层级，角色使用头像网格，详情包含角色、武器、技能、装备图标与属性分区，真实资源比例使用进度条。复用鸣潮/异环既有公开素材目录，独立公共缓存无账号认证；游戏几何徽标为本项目原创，并非官方美术。终末地角色素材来源未验证，缺图如实降级。来源和安全边界见 [公开图标](qq-public-assets.md)。
- 查询只读已有缓存，刷新指令才显式提交已有能力队列。未知、未采集、失败保留旧数据、历史不完整分别说明。v2正常长列表完整绘制，不再六条分页；达到文档/像素/体积边界明确提示，不能把省略内容当完整。所有时间按北京时间显示到分钟，日期本身只有日精度时不编造时间。
- 鸣潮抽卡读取已存在的本人作用域账本，未导入时提示网站操作。鸣潮详细属性/技能/声骸读取最近100条本人详情观测中的精确角色匹配；未命中说明详情未采集或不在近期缓存，需在网站查看角色后再查，不从QQ发起上游详情请求。
- 异环角色/武器/技能来自现有角色缓存，官方配队只呈现来源资料，不自动生成推荐。资源报表是期间获取量，不冒充钱包余额。
- 终末地鹰角寻访与森空岛档案分区显示，禁止合并不同身份。森空岛的干员、装备、体力、探索等从其已有账号快照投影；无该授权时给出所需授权提示。终末地仍无真实测试账号。
- 显示数据以明确字段投影，不输出原始上游载荷或凭据；UID脱敏。综合图片缓存包含全部账号/角色/授权版本/快照指纹，渲染后再检查QQ绑定及全部授权。
