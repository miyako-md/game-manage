# 异环社区抽卡统计展示

2026-09-16 按用户提供的小黑盒截图重排展示，数据仍来自已登录塔吉多的 `/apihub/awapi/yh/gacha`。默认入口改回「抽卡统计」，本地逐抽账本保留在折叠的可选工具中，默认不请求账本接口。

## 官方标签依据

通过塔吉多 APP 的 `/apihub/api/getCommunityHome?communityId=2` 确认「抽卡分析」入口为 [官方 scard 页面](https://webstatic.tajiduo.com/bbs/scard/index.html)。核查其当前公开脚本 [main.149e4946.js](https://webstatic.tajiduo.com/bbs/scard/static/js/main.149e4946.js)：

| 字段 | 口径 |
| --- | --- |
| `luckTitle` | 整体近期评价称号，直接展示服务端文本，不按本机平均抽数计算 |
| `luckType` | 官方称号底色分段：1–5、6–10、11–15；未知值使用中性样式 |
| `details[].luckyType=0` | 不显示评价标签，黄色横条 |
| `luckyType=1` | 超欧，绿色横条 |
| `luckyType=2` | 欧，绿色横条 |
| `luckyType=3` | 非，黄色横条 |
| `luckyType=4` | 超非，红色横条 |
| 其他或缺失 `luckyType` | 不猜标签，灰色横条 |
| `rareCount / m` | 官方横条比例，超过 100% 时封顶。缺失标尺时保留抽数文本但不绘制比例 |

官方脚本为 1/4 提供图形徽标，同时定义了 2/3 的中文含义。本项目使用自有 CSS，展示四种明确含义的文字标签，不复制官方图片徽标。未采用第三方代码中与实测不符的 `3=极欧` 注释，也不自行设定欧非抽数阈值。

头像优先复用角色快照，缺少时使用官方工具的资源路径：`yh-game-records-web-source/character/tall/{数字ID}.PNG`；弧盘为 `character/fork/{fork_ID}.png`。名称保持已有解析口径，未匹配名称的弧盘保留 ID，图片失败回退文字。

## 界面与边界

- 顶部并列限定、常驻、弧盘统计：抽数、出 S 数量、S 级平均。
- 下方切换卡池，展示头像、名称、北京时间、彩色条和官方评价。
- 近期评价与读取时间分开显示；读取时间不意味着游戏数据已实时同步。
- 条目抽数表示本次出 S 所用抽数，不等于当前垫抽。保留社区记录顺序。
- 没有完整逐抽流水和可靠的十连批次字段，不根据相同时间直接增加「十连二金」标签。
