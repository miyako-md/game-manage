# 异环图标目录

`frontend/src/nte-icon-catalog.js` 是独立的公开名称、ID 和图标 URL 常量，不含账号、凭据或个人养成数据。核验日期：2026-09-26。所有入库图片均来自塔吉多官方 CDN；元数据镜像用于名称与 ID 对照，不将镜像维护者当作游戏官方。

## 来源与覆盖

| 分类 | 已验证覆盖 | 映射来源 |
| --- | --- | --- |
| 角色 | 24 个角色 ID，含男、女零；30 个名称键含明确别名 | [官方配队接口](https://bbs-api.tajiduo.com/apihub/awapi/yh/team)直接返回 ID、名称和方形头像 URL；[NteMeta 角色表](https://cnb.cool/tyql688/NteMeta/-/blob/7d8df4235351116d462546c22991c71d423c2019/char_meta.json)补充明确别名 |

| 卡带套装 | 12 套；14 个名称键含冒号/间隔号写法 | [游戏原始套装表公开镜像](https://github.com/Waifus-Grace/NTE_Assets/blob/ae1f348c35378184a9e14b56593f43854b7ce575/DataTable/Equipment/DT_EquipmentSuitData.json)中的行 ID 与 `SuitTitle.LocalizedString` |

[官方战绩前端](https://webstatic.tajiduo.com/bbs/yh-game-record/index.html)定义以下图片路径；本项目按明确元数据 ID 组装后逐条验证，未按名称猜测文件名：

```text
https://webstatic.tajiduo.com/bbs/yh-game-records-web-source/character/
  fork/{fork_id}.png
  suit/detail/{suit_id}.png
  skill/{skill_id}.png
  city_skill/{skill_id}.png
  element/{CHARACTER_ELEMENT_TYPE_*}.PNG
```

## 核验与边界

- 对 287 个候选唯一 URL 逐一 GET，核对 HTTP 200、图片 Content-Type 和 PNG 文件签名：273 个通过、14 个 404。再对官方 `NATURE` 属性图标单独 GET 验证通过，最终目录包含 274 个唯一有效 URL。未来 CDN 可变化，前端仍须保留图片失败后的名称占位。
- 当前攻略使用的全部 17 个弧盘名称（将原误写“运行者之声”纠正为“远行者之声”后）、5 套卡带，以及 5 位已整理角色的普通攻击、变轨技能、极轨终结、援护技、被动 1/2 均有图标。角色索引 23 项中，22 个明确角色有头像；“主角·零”指代性别不明，应保持名字占位，实际角色 ID 1046/1051 可以精确匹配男/女头像。
- 技能同时按实际名称与明确类别索引。被动按源数组顺序编号；同类都市特技分别编号；不把不同角色的同类技能互相替代。目录中的明音凛 `1057` 技能映射为空，不能声称已覆盖后续版本新增角色。
- 404 缺口：明音凛头像及 9 个技能/都市特技、弧盘“月的对跖点” `fork_prism`、卡厄斯“尘中影” `ga_chaos071_passive_3`、真红“威慑凝视” `ga_shinku_passive_3`。这些图标未收入可显示条目。
- 另一个失败候选是镜像元数据中的 `Anima` 属性编码；官方战绩使用 `NATURE` 表示灵属性，已依据实际接口枚举纠正并验证，未将不存在的 `ANIMA` URL 留在目录。
- 12 套来自本次原始套装表，不能据此声称涵盖游戏未来所有套装。套装图标不表示驱动块形状、摆放位置或卡带主副词条；攻略原图仍承担这部分信息。
- 官方配队接口把 1039 写作“法蒂娅”，游戏元数据写作“法帝娅”，二者同 ID，可兼容检索。`光波眩晕` 为 `光波眩晕，迷走狂欢` 的攻略简称；冒号与间隔号的套装名称均有兼容键。不保存“运行者之声”这个错字别名。

维护时先更新明确元数据来源，再核对名称、角色 ID 和技能类别，最后验证官方图片。只有 HTTP 可用不能证明任意名称映射正确；无可靠映射时保留名称与原图入口。

## 页面集成与验证

异环主页面改为模块概要卡，详情统一在原生弹窗中按需挂载；角色练度、房产载具、配队、抽卡、攻略及资讯使用同一弹窗壳。角色概要预览、角色练度的弧盘/战技/都市技能，以及攻略中的推荐实体接入图标目录。长段补充说明折叠，名称、推荐排序、版本和适用条件保留。未知图标、无法确定性别的泛称主角和加载失败图片均保留文字占位。

前端 168 项通过，后端攻略专项 12 项通过，生产构建成功。浏览器验证桌面及 390×844 布局；攻略初始可视区域 24 张实体图片全部加载成功，黑羽加点的 4 张角色专属技能图标另行核对。Esc、关闭按钮、遮罩点击后卸载详情并恢复页面滚动和入口焦点。独立代码复核未发现 Important/Critical 问题。

声骸属于鸣潮，沿用同一工作区已有的 `wuwa-icon-catalog.js`：199 个声骸名称条目、122 个武器名称条目、34 套套装、46 个角色形态的 322 条技能映射。本轮对角色、武器、声骸、套装各抽查 3 个官方地址，共 12 个均返回 200 与 image/png；此为可用性抽样，不是全目录重新核验，也不是本轮新增的异环数据。
