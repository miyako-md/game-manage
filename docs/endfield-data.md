# 终末地数据展示与来源

在「社区账号」用鹰角通行证手机号登录终末地（目前只支持官服），然后从左侧进入「终末地」，点击「刷新数据」。

2026-09-28 已扩展为[终末地工具箱](endfield-toolbox.md)。官网公告、地图目录与点位已实测；私人账号接口尚未经真实账号验证，需用自己的官方会话核对。

| 区块 | 来源 | 展示口径 |
| --- | --- | --- |
| 账号概览 | 通行证授权 → `binding_list?appCode=endfield` | 官服角色昵称、等级、服务器、渠道；角色变化时提示重新登录 |
| 寻访记录 | 通行证授权 → `u8_token_by_uid` → `ef-webview.hypergryph.com/api/record/*` | 按卡池统计总抽数、6★/5★ 数量、距上次 6★ 的抽数、6★ 历史；逐条记录可分页查看和导出 |
| 资讯 | 终末地官网；没有官网快照时回退 B站官号 `明日方舟终末地`（UID 1265652806） | 保留真实来源和同步状态 |
| 活动日历 | 官网全文版本说明与寻访说明 | 见下文“公告解析” |

理智、每日活跃、协议通行证、干员练度、地区探索、帝江号、挑战和签到使用独立森空岛连接。在终末地概览连接自己的官方会话并选择角色，程序不会伪造设备指纹。地图检索与蓝图收藏无需账号，详见工具箱说明。

## 寻访记录

- 官方记录页明确说明可查近 90 日，结果约有 30 分钟延迟（2026-09-28 核对官方前端脚本）。本工具从第一次同步开始，把记录保存在数据库旁的 `*.endfield-gacha.sqlite3`，按角色隔离；退出登录不会删除账本。
- 同步以 `seqId` 去重。每次最多请求 120 页（每页 5 条，页间隔 0.3 秒）；首次同步没翻完的部分会记为待续传区段，下次「刷新数据」或 4 小时一次的自动同步接着翻。
- 翻到官方窗口尽头仍没接上本地更早的记录时，记为永久缺口（例如超过 90 天没同步）。
- “距上次 6★”只在连续记录中给出确定值；跨过缺口，或统计范围里有免费寻访（是否计入垫抽尚未核实）时，显示“至少 N 抽”；没有记录时显示未知。不内置保底数值，也不判断是否“歪”。
- 目前查询五种角色池类型：特许寻访、重构寻访、基础寻访、启程寻访、辉光庆典；武器池按接口返回的池列表逐个查询。重构寻访类型由官方记录页核实。未来新增类型仍需在 `adapters/endfield/endpoints.py` 的 `CHAR_POOL_TYPES` 中补充。
- u8_token 只在单次同步中使用，不写入磁盘或日志；导出文件不含任何凭据。

## 公告解析

终末地公告用「版本名」标识版本，条目标题形如 `1.「冬猎」特许寻访`，时间行形如 `开放时间：<开始> - <结束>（服务器时间）`。解析器在 `sources/endfield_notice.py`，要点：

- 以最新一篇已开始的「X」版本更新说明为基准；之后发布的单独寻访说明、活动说明会补充或覆盖同名条目。
- “「X」版本更新后”“版本开启后”只保留开始日期，不填具体时刻。
- 结束写作“版本更新维护前”或“「X」版本期间”时，先显示“截止未知”；下一版本的维护预告（例如“计划将于 2026年6月5日 06:00 开始……停机维护”）发布后，用其开始时刻补全。
- “于3次「特许寻访」后结束”这类依附结束不推算，原文保留在详情里。
- 常驻内容和只有开放时刻的玩法更新不进日历。
- 官网活动已接入适配器 `EVENTS` 轮询；明确的截止时间按已有提醒设置触发临期通知，未知截止不推算。
