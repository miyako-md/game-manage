# 鸣潮角色攻略

入口：鸣潮 → 角色 → 选择角色 → 在弹窗内切换实际面板／培养攻略。

## 资料与版本策略

首批收录 46 种角色形态的库街区公开攻略摘要。使用游戏角色 ID 匹配，气动秧秧、秧秧·玄翎和不同属性漂泊者不能按名字混用。

没有最低版本门槛。优先采用内容可信、角色定位匹配且较新的资料；旧版保留版本号。每一类建议单独关联来源，不能把旧版技能建议改标为新版。例如折枝配装引用 3.6 图文，技能引用 3.5 文字。达妮娅配队引用 3.6，武器与聚爆／集谐配装补用 3.3。

适用版本、发布时间和核查日期是不同字段。无法确认版本时显示“版本未确认”；未上线版本显示“前瞻”，不作为已核对推荐。补充来源仅提供阅读入口，视频未转写的内容不能当作已经提炼完成。

这是可离线展示的资料快照，**不自动更新、不宣称全站最新或数值最优**。角色页不会实时调用库街区搜索、发送用户令牌或读取抽卡记录。

## 提炼核查（2026-09-25）

检查 46 × 5 = 230 个条目槽位：217 项完成原帖摘要核对，7 项只有部分资料，6 项没有足够明确的来源内容，保留“待核验”。“已核对原帖”指提炼与出处对应，不等于对社区攻略进行游戏实测或伤害计算验证。

五类条目为武器、配队、声骸配装、主副词条、技能优先级。旧版信息可用，但必须保留原来的玩法条件；大世界、治疗、主 C／副 C、共鸣链、武器谐振等条件不得省略成无条件最优结论。

发现并处理的典型问题：

- 图片 OCR 会将技能图标标签按错误顺序拼接。穗穗、相里要、椿、清宵等技能顺序已回看原图；不是把 OCR 结果直接当作排名。
- 气动主有一篇标题似攻略、正文实际提问的帖子，未使用。
- 气动秧秧原帖 COST 标签重复，未猜测 3C 推荐，字段标为“部分资料”。
- 弗洛洛原帖的技能伤害副词条建议有待进一步核查，只保留能明确支持的双暴与攻击方向。
- 莫特斐原帖引言误写其他角色，标题和首图均核实为莫特斐 2.6；没有依据错误引言匹配角色。
- 较新文章缺少某些栏目时，用旧版来源补充并单独标注，而不是从角色机制自行生成答案。

## 实现与维护

- `frontend/src/wuwa-guides-catalog.js`：经过审读的公开资料摘要，不含用户 UID、凭据、持有状态或练度。每个角色包含来源及五个有状态的条目。
- `frontend/src/wuwa-guides.js`：严格角色 ID 匹配、版本标签和原帖 URL 白名单。
- `frontend/src/components/WuwaGuide.vue`：按条目显示版本、作者、出处、缺项；窄屏单列，使用现有主题变量。
- `frontend/src/components/WuwaRoles.vue`：在既有详情区增加实际面板／培养攻略切换。攻略不依赖私人角色详情请求成功，切换角色时同步切换资料。

更新资料时修改目录中的对应条目，保留已有来源 ID 和版本；新增条目必须核查正文／图片及角色形态。`reviewed` 要有明确文本；`partial` 必须说明缺少什么；`pending` 不得填入推测建议。来源关联与状态约束由测试校验。

原始图文和本机 OCR 属于本地调研材料，未将整篇文章或原图打包进产品。摘要采用简短事实与建议，保留作者及可跳转出处。

## 验证

`npm test` 覆盖角色形态隔离、逐项版本关联、缺项状态、危险链接拒绝、账号面板故障时攻略仍可用，以及切换角色后不残留旧攻略。前端构建通过；本地 8010 页面检查攻略页签、混合版本与原帖链接。

## 弹窗和官方图标（2026-09-26）

角色详情使用原生 modal dialog；窗口内切换实际面板与攻略，支持关闭按钮、Esc 和点击遮罩。打开时锁定背景滚动，关闭或卸载时恢复滚动及原焦点。实际面板的长技能说明、共鸣链效果、武器与套装效果默认折叠，保留完整原文。

图标来源为库街区官方接口和[官方图鉴](https://wiki.kurobbs.com/mc/home)，未使用不明来源的同人图替代：

- 官方图鉴公开目录返回 64 个角色条目、122 把武器、199 个声骸、34 套合鸣效果，均附图片地址。
- 角色详情接口补充 46 个角色形态的头像、322 个主要技能图标，以及当前装备与属性图标。
- `wuwa-icon-catalog.js` 只记录公共名称、图片地址和角色／图鉴标识，未记录账号 UID、等级、装备归属或凭据。合并后的角色名称索引有 65 项，包含漂泊者名称规范化项，不代表 65 位独立角色。
- 图鉴获取：`POST /wiki/core/catalogue/config/getTree` 与 `POST /wiki/core/catalogue/item/getPage`；表单请求，公开请求头 `source=h5`、`wiki_type=9`，没有附加账号令牌。后者参数为 `catalogueId`、`page`、`limit`；本轮目录 1105／1106／1107／1219 均读取到完整分页总数。
- 现有角色详情 `POST /aki/roleBox/akiBox/getRoleDetail` 的鉴权仍由项目原有服务处理。只将响应中的公共图标元数据加入前端目录。

攻略显示层按完整名称优先匹配图标，逐字保留原文中的“或”、并列、优先级和适用条件；不会因图标目录排序而生成推荐顺序。技能严格按当前角色 ID 匹配。实际面板使用实际装备返回的图标，不使用推荐装备图标替代。

图片地址限定为官方 HTTPS 图片域名，失败时显示名称占位并保留文字。当前五篇攻略里的“固有技能”没有可唯一对应的图标，保留占位；泛指的“常驻五星”“治疗”等也不擅自映射到某件装备或角色。图标远程加载，离线或 CDN 失败不会使攻略文字丢失。

验证：150 项前端测试通过；生产构建通过。浏览器确认原生模态状态、23 个可见攻略图片均加载、Esc／遮罩关闭及焦点和滚动恢复；390px 视口下无横向溢出。未把图标 URL 白名单校验等同于全量远程图片逐张验收。

## 其他模块弹窗与挑战攻略（2026-09-26）

档案、体力、周期进度、探索收集、数据坞、资源简报、各玩法、抽卡历史、成长记录和公告详情统一使用弹窗。列表页保留概要和来源状态，详情按需挂载；账号切换会移除原账号弹窗，关闭抽卡弹窗会取消未完成的文件读取。打开抽卡历史只读取本地档案，导入仍由用户主动触发。公告详情保留已有摘要与原文链接，不宣称抓取了全文。

挑战总览分为逆境深塔、战术全息、冥歌海墟，详情内切换“战绩详情／社区攻略”。社区攻略静态目录为 `frontend/src/wuwa-challenge-guides.js`，本轮核查 20 篇公共原帖，覆盖 12 位全息首领。深塔和海墟保留适用期次、半场、队伍或难度；全息可按首领精确筛选，未收录首领显示空态，不使用其他首领攻略填补。

来源通过库街区公共接口 `/forum/search/v2/post` 和 `/forum/getPostDetail` 搜集，未携带用户账号令牌。每篇保留作者、发布日期、版本依据、适用范围及官方原帖链接，按发布日期较新优先排列。版本不明确时显示“版本未确认”。视频仅核查公开标题与说明，明确标记未转写；局部机制和单通演示不包装成完整通用攻略。

当前目录是人工核查快照，尚未自动更新，也未自动匹配本期增益和首领环境；收录数量不代表覆盖全部挑战与首领。更新时需重新核对原帖，不能按发布日期推测版本。

深塔展示规则后续调整：仅显示适用周期包含当前时间的图文攻略，隐藏旧期、视频和通用入门帖。当前轩儿 2026-09-14～10-12 期的六张原帖配图可直接切换查看；北京时间 10 月 12 日 04:00 到期后不再展示，没有新一期资料时显示等待更新。有效期来自原帖日期范围与已核查的深塔重置时刻，不能用帖子发布日期替代。其他挑战保留原筛选规则。

验证：158 项前端测试通过，生产构建通过。新增回归覆盖按需挂载、账号切换关闭、仅打开抽卡历史不触发导入、首领精确匹配、缺失攻略空态，以及玩法弹窗和公告空态保留采集错误与旧数据状态。浏览器验证档案、玩法、资源和挑战详情；验证 Esc 关闭、焦点恢复、全息首领筛选与缺失提示。390px 视口下文档和弹窗均无横向溢出。测试未进行真实抽卡导入或历史回补。
