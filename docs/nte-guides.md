# 异环角色攻略

入口：游戏档案 → 异环 → 角色与探索 → 查看角色攻略（“全部”中也显示攻略概要）。详情在弹窗中按需加载，关闭后卸载。无需登录即可浏览公开攻略；“只看已拥有”根据当前角色快照的名字和明确别名匹配，快照未取得时提示关闭筛选或刷新角色资料。

角色、弧盘、卡带套装及技能使用名称加官方图标展示；适用条件与补充说明折叠，推荐顺序和条件仍完整保留。图标按准确名称、角色 ID 和技能类别关联，不跨角色借用图标。图标覆盖及缺口见 [异环图标目录](nte-icons.md)。

## 本轮内容

23 名角色的原图目录，其中黑羽、残虹、灵可、伊洛伊、娜娜莉已逐项核对弧盘、配队、卡带配装、主副词条、技能加点五类摘要。其他 18 名角色直接展示来源和对应页码，文字摘要明确标为待整理，不把缺资料填成通用推荐。

来源是社区作者建议，不是官方推荐，也不意味着当前版本最优。黑羽采用 V1.4 攻略，其他目录基于 V1.3；查验日期为 2026-09-26。版本跟随来源，不因刷新时间较新而改为新版本。两篇文章均为轩儿Zero发布：

- [黑羽 V1.4 培养攻略，495234](https://www.tajiduo.com/bbs/index.html#/post?postId=495234&id=2)：5 张图，页 2 为卡带与词条、页 3 为加点、页 4 为弧盘、页 5 为配队。
- [V1.3 全角色养成一图流，491439](https://www.tajiduo.com/bbs/index.html#/post?postId=491439&id=2)：6 张图、22 个角色；每名角色映射其所在页。原图保留署名水印，页面提供原帖及原图链接；不将图打包进仓库。

## 读取方式

使用匿名 `GET https://bbs-api.tajiduo.com/bbs/wapi/getPostFull?postId=…` 获取已收录原帖的完整正文、作者、发布时间、实际编辑时间和图片列表。不会依赖列表中可能截断的 300 字摘要，也不请求用户的游戏账号或社区凭据。

这是一版人工核对的攻略目录，不是运行时自动搜索、自动 OCR 或自动大模型总结。新增角色或更换攻略需要更新 `nte_guides_catalog.py` 并核对对应五类信息。用户给出的版本/专武/觉醒条件不得在摘要中丢失。

## 缓存与变更

- 数据库：`db_path` 同目录的 `.nte-guides.sqlite3` 独立公开来源缓存，不修改角色或抽卡账本。
- 成功资料保留 24 小时；点击“刷新原帖”主动读取，同一来源 30 秒内避免重复访问。
- 比较原帖标题、正文和图片链接指纹。发生变化时提示“原帖有更新，文字摘要待复核”，保留旧摘要的核查日期，不自动重写推荐。
- 网络错误、帖子删除、异常响应时保留最后一次成功资料及原读取时间；失败状态持久化，重启后仍会提示并重试。
- 若图片内容在相同 URL 下被替换，纯元数据指纹不能检测全部变化。摘要仍需定期人工核对，不能保证永远最新。

## 接口与边界

| 本地接口 | 功能 |
| --- | --- |
| GET `/api/nte/guides` | 角色目录、五类摘要、来源及版本 |
| GET `/api/nte/guides/sources/{post_id}` | 读取来源缓存，缺失/过期时匿名拉取 |
| POST `/api/nte/guides/sources/{post_id}/refresh` | 主动刷新已收录来源，要求 `X-Game-Assistant: 1` |

沿用全局本机 Host/Origin 边界。只接受目录内的帖子 ID，不接受任意 URL；请求不跟随重定向，响应上限 2 MiB，正文限制 20 万字符、图片最多 40 项。正文转为纯文本，不渲染第三方 HTML。图片仅允许塔吉多指定 HTTPS 域名；不安全 URL 置空，保留原图页码和重复页，避免角色页码错位。
