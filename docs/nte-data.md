# 异环数据展示与来源

在「社区账号」完成异环登录后，从左侧进入「异环」，点击「刷新数据」。

| 区块 | 来源 | 展示口径 |
| --- | --- | --- |
| 账号概览 | `/apihub/awapi/yh/roleHome` | 昵称、角色等级、世界/大亨等级、活跃天数、角色/成就/房产/载具数量 |
| 体力与日常 | 同上 | 本性像素、都市活力、日常活跃、周本剩余；上游缺字段显示未提供，不推测恢复时间 |
| 角色练度 | `/apihub/awapi/yh/characters` | S/A等品质、角色等级、元素、觉醒、混频、羁遇累计经验；展开弧盘、属性、战技及城区技能 |
| 成就进度 | `/apihub/awapi/yh/achieveProgress` | 成就已完成/总数、铜银金奖牌、分类进度，不是周期挑战 |
| 探索进度 | `/apihub/awapi/yh/areaProgress` | 各区域及子项的探索数量；仅分子已知且分母>0时显示百分比 |
| 抽卡统计 | `/apihub/awapi/yh/gacha` | 分卡池统计抽数、出S数量、平均出S抽数；仅展示已经出S的明细与本次出S抽数 |
| 社区名片 | `/apihub/api/getGameRecordCard` | 仅展示当前角色的异环社区名片，不是对局战绩 |

公告及手填活动日历沿用原实现。

## 与鸣潮的区别

- 异环使用独立模型和卡片，不使用鸣潮的五星、6链、90级满级统计。
- `alev` 是角色等级，`awakenLev` 是觉醒等级，`slev` 是混频等级；`likeabilitylev` 是羁遇累计经验，并非好感等级。
- `progress` 是已探索数量，不是直接的百分比；null 不等于 0。
- 实测部分累计数高于接口目标值，保留原始数量；完成度封顶 100%，超出目标时显示“已达目标”。
- 抽卡池的 `rareCount` 是出S总数，明细中的同名字段是本次第几抽出S；接口不含当前垫抽与完整抽卡流水，不能推算当前保底或终身统计。
- 周本剩余字段为可选，未返回时不显示 0。恢复时间、周期重置时间也不会自行推算。
- 社区名片接口可以合法返回空列表，此时显示「暂无社区名片」。

## 数据与失效处理

七类私人快照都带 `schema_version: 1`。升级前保存的原始响应会在页面提示刷新，避免误显示零值。解析失败保留上次成功快照；登录失效交由现有令牌刷新流程处理。

同一角色和登录 token 的 roleHome/characters 响应短暂缓存 30 秒，减少一次全量刷新中的重复请求。token 或角色变化立即停止复用缓存。头像地址指向塔吉多官方 CDN；图片加载失败可显示角色文字占位。
