## 与鸣潮的区别

- 异环使用独立模型和卡片，不使用鸣潮的五星、6链、90级满级统计。
- `alev` 是角色等级，`awakenLev` 是觉醒等级，`slev` 是混频等级；`likeabilitylev` 是羁遇累计经验，并非好感等级。
- `progress` 是已探索数量，不是直接的百分比；null 不等于 0。
- 实测部分累计数高于接口目标值，保留原始数量；完成度封顶 100%，超出目标时显示“已达目标”。
- 抽卡池的 `rareCount` 是出S总数，明细中的同名字段是本次第几抽出S；接口不含当前垫抽与完整抽卡流水，不能推算当前保底或终身统计。
- 周本剩余字段为可选，未返回时不显示 0。恢复时间、周期重置时间也不会自行推算。
- 社区名片接口可以合法返回空列表，此时显示「暂无社区名片」。

## 数据与失效处理

结构化私人快照都带 `schema_version: 1`。升级前保存的原始响应会在页面提示刷新，避免误显示零值。解析失败保留上次成功快照；登录失效交由现有令牌刷新流程处理。官方配队是公共快照，退出登录时保留。

同一角色和登录 token 的 roleHome/characters 响应短暂缓存 30 秒，减少一次全量刷新中的重复请求。token 或角色变化立即停止复用缓存。头像地址指向塔吉多官方 CDN；图片加载失败可显示角色文字占位。

2026-09-15 修正：手动刷新会先清除 roleHome/characters 缓存，再重新查询；失效前发出的请求不会重新填回已清除的缓存。一次刷新内部的账号与体力仍复用本次查询，避免重复请求。体力显示实际读取时间，不将缓存再次保存的时间当成新的读取时间。

上游同步限制：当日用户报告游戏内本性像素为 0，直接绕过本地缓存并使用 HTTP no-cache 请求 `roleHome` 仍返回 320/320；绑定角色已核对一致。所检查的参考客户端也使用该端点，目前未找到并验证独立强制同步接口。清除本地缓存不等于让塔吉多立即同步游戏；不能把用户报数写死为接口值，也不能将 HTTP 成功视为已与游戏一致。卡片明确提示数据可能延迟。
