# 游戏管家工作台与活动时间轴设计

用户已选定：C 的深蓝金色配色 + A 的侧栏工作台布局；活动日历为独立页面，参考用户提供的版本日历长图，采用日期横轴、分类行与起止活动条。

## 产品结构

- 侧栏：今日总览、活动日历、我的游戏（逐游戏）、社区账号。窄屏提供可操作的收起导航。
- 总览：游戏摘要、体力及临期提示、近期活动、公告资讯；全部读取真实快照，不添加虚构数值。
- 游戏详情：全宽布局、能力分区网格，保留全部原生卡片与登录数据口径；LoL news 使用公告列表组件显示。
- 社区账号：独立页面，保留原 LoginPanel 行为、人工验证及登录事件；不自动发送短信或退出。
- 日历：月范围/14天范围、前后翻页、回到今天、游戏筛选、按游戏与活动类型分组、时间条、今天标线、详情面板。支持独立 hash 路由及浏览器前进后退。

## 时间与数据约束

- 北京时间统一显示。数据过期与读取失败可见，读取失败时保留上次成功显示。
- 起止齐全：依照真实时间比例定位，范围外部分裁剪且可在详情查看完整日期。
- 只有单侧日期：显示日期标记与未知端点说明，不推测完整周期；无日期或异常区间单独展示。
- 显示截止时间、分类、来源标题、抓取时间，只有合法 http(s) 原文链接才提供跳转。
- 日期只来自现有 events 数据。截图的角色活动美术无对应数据时使用分类纹理与游戏色，不冒充真实活动图片。
- 登录切换清理旧私人摘要并阻止在途旧请求重新写入。
- 维持每60秒读取本地快照；手动刷新通过现有API触发采集。
