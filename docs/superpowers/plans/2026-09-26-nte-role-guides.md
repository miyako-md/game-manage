# NTE Role Guides Implementation Plan

**Goal:** 按已确认的“角色推荐摘要＋原图＋来源版本”增加异环角色攻略模块。
**Architecture:** 独立公开攻略目录、匿名原帖读取与 SQLite 缓存；Vue 独立攻略页。首批五名角色整理五类推荐，23 名角色可定位已核查的原图页；摘要与原帖版本分别记录。
**Tech Stack:** Python/FastAPI/httpx/SQLite、Vue3、pytest/node:test。
**Spec:** 用户本轮确认的来源验证结论及下列约束。

## Constraints and rulings
- 保留现有未提交的鸣潮 UI 工作；本轮只新增异环文件，并最小修改 api.py / GameCard.vue。
- Ruling: 在当前目录集成，避免搬移正在使用的未提交界面；不切分支、不提交、不推送。
- 不新增登录、抓包、收费 API 或运行时大模型依赖。文字推荐来自本轮逐项核对，原图保留作者水印、署名和原帖链接。
- 社区建议不是官方结论；角色、玩法条件、适用版本必须随推荐显示；18 名未整理角色只显示原图索引及待整理状态。
- 原帖变化后摘要标为待复核；来源不可达保留旧快照并说明。不得把 GET 阅读失败覆盖为成功空结果。

## Tasks
- [x] 1. 新增 nte_guides_catalog.py：来源、摘要、23 名角色目录和页面索引；核对黑羽、残虹、灵可、伊洛伊、娜娜莉五类推荐。
- [x] 2. 新增 nte_guides.py / nte_guides_routes.py：来源限制、大小限制、纯文本清理、指纹、持久缓存、失败回退、同源并发去重和刷新节流。tests/test_nte_guides.py 覆盖坏响应、缓存重启、内容变更、请求保护与未知 ID。
- [x] 3. 新增 NteGuides.vue / nte-guides-api.js：检索/拥有筛选、推荐摘要、来源版本、原图翻页和刷新；保持失效状态与竞态隔离；最小集成 GameCard 的角色攻略标签，不加入私人能力轮询。
- [x] 4. 运行专项与整套测试、构建；独立复核本轮文件；启动当前版本，浏览器验收五类推荐、图片、筛选、刷新与窄屏。更新 docs/nte-guides.md 和本计划。

## Review focus
- 匿名读取失败、帖子删除、恶意 HTML/图片 URL、缺作者/缺正文时保留可靠状态。
- 旧版攻略不得因为来源刷新成功而获得“当前版本”标记。
- 快速切角色或关闭组件时旧请求不得覆盖新角色内容。
- 无已登录角色时仍可浏览公开攻略；拥有筛选明确无资料状态。
- 原帖更新或图片链接改变使摘要失效；图片内容原 URL 被替换无法由元数据指纹完全检测，保留此限制。
