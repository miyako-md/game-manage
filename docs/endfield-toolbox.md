# 终末地工具箱

更新日期：2026-09-28。此文记录本次实现；早期可行性和实施指导中的“尚未接入”不再代表当前功能。

## 页面与数据来源

终末地档案沿用全站卡片、按钮、字号、间距、游戏强调色和亮暗主题，提供概览、干员与探索、挑战记录、抽卡统计、地图与图鉴、蓝图收藏、公告与资讯七个分区。

| 功能 | 数据来源与使用条件 |
| --- | --- |
| 官网公告与活动日历 | 读取终末地官网的公告列表和全文；复用终末地公告解析规则。没有成功的官网快照时回退 B站官号内容；已有官网数据时保留原来源与日期。 |
| 寻访记录 | 原鹰角通行证官服登录与本地账本；增加官方记录页已使用的重构寻访类型。 |
| 个人档案 | 用户在本机连接森空岛官方会话、选择绑定角色后读取；显示账号、理智恢复、日常与通行证、干员、地区据点与收集、帝江号、成就。干员列表与详细配装使用两个官方接口，点击“查看配装”后按需读取技能、武器、基质与装备；未开放的详情会说明不可查。缺失值保留未知，不按零处理。 |
| 挑战记录 | 从森空岛读取战争回响、影拓丰碑、危机合约的结构化记录；尚未开放或不可见的内容显示上游状态。 |
| 签到 | 主动点击时才提交签到。日历状态和奖励按森空岛返回展示，失败不会标成已签到。 |
| 地图 | 无需账号，读取官方地图目录、区域、点位类别、坐标与详情；按地图和区域按需加载，支持筛选、搜索和分页。 |
| 图鉴与配队养成 | 通过森空岛会话查询干员、武器、装备、战术物品和养成材料五类目录，支持搜索与分页；配队和养成建议提供官方工具入口。无法获取时明确提示。未把未经完整核实的队伍查询和完整背包声明为已实现。 |
| 蓝图收藏 | 手动保存蓝图名称、分享码和备注；支持修改、删除、复制及导出。只保存在本机，不扫描游戏内工厂，也不把分享码提交到外部网站。 |

森空岛角色和鹰角寻访角色各自独立。页面分别显示身份；切换角色或断开森空岛连接会清除其旧档案缓存，避免把两个账号的数据拼在一起。

## 连接森空岛

在终末地“概览”中展开连接区域，使用自己已登录的官方森空岛网页会话凭据。若官方要求设备信息，可填入同一官方会话的原生设备标识。程序不生成替代设备指纹，也不调用第三方转发服务。连接验证成功后，选择返回的终末地角色再读取档案。

会话凭据通过现有 `CredentialStore` 加密，保存在数据库旁的 `*.endfield-skland.credentials.json`；Windows 使用当前用户的 DPAPI，其他系统沿用项目现有本机加密方式。短期签名令牌只在内存中使用。页面状态、日志、蓝图与抽卡导出均不包含凭据。请不要把任何凭据贴进问题反馈或拉取请求。

授权过期或平台设备校验拒绝时，需要重新连接自己的官方会话。程序不承诺此类内部接口长期不变。森空岛返回成功且身份与所选角色一致后才更新档案；失败保留本次运行中已取得的数据并标记陈旧。

## 日期、刷新与存储

- 官网公告、地图目录与点位缓存保存在 `*.endfield-public.sqlite3`，按需读取，主动刷新可更新公告。网络或格式异常保留上次成功缓存并说明失败。
- 官网 `NEWS` / `EVENTS` 接入原调度器与活动提醒；只有明确、带时区的截止时间参与临期提醒。
- “版本更新后”保持相对开始；“版本更新维护前”只有在后续维护公告发布后才补上时间；“于三次寻访后结束”等文字不猜测日期。
- 官方寻访页现明确说明可查近 90 日且约有 30 分钟延迟。本地账本长期保存已同步记录；超出官方窗口且本地从未保存的历史无法补回。
- 重构寻访使用独立类型 `E_CharacterGachaPoolType_Rerun`，与特许寻访分开统计。其他新类型仍需按官方页面更新。
- 蓝图收藏存于 `*.endfield-blueprints.sqlite3`，与任何游戏账号退出操作无关。支持导出备份，单机最多 1000 条。

## 验证范围

2026-09-28 已实际读取官网公告与全文、官方地图目录、类别和区域点位，并核对官方寻访页脚本中的重构寻访枚举及 90 日说明。测试使用固定样例验证解析、失败保留、日期规则、账号隔离、请求签名、蓝图保存导出和页面交互。

未使用真实个人账号验证鹰角短信、森空岛档案、签到写入与私人挑战记录。测试通过表示实现行为经过检查，不表示任意账号、渠道服或所有版本的上游接口已经实测。B服与国际服的独立登录流程不在本次接入范围内；完整背包、邮件、全部任务明细和个人设施地图没有作为已实现功能发布。
