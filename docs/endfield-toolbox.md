# 终末地工具箱

更新日期：2026-10-18（云端同角色档案合并）；首版 2026-09-28。此文记录当前实现；早期可行性和实施指导中的“尚未接入”不再代表当前功能。

## 页面与数据来源

终末地档案沿用全站按钮、字号与亮暗主题，以直角面板、编号、黄青强调和角标组织报告。主要导航为概览、全员练度、地区建设、帝江号与抽卡统计；光荣之路、挑战、资讯和原有工具收进“更多”，手机分两行显示主导航。森空岛连接与角色切换压紧为一栏，鹰角寻访账号独立说明。本期暂缓蓝图扩展、生产计算器、互动地图、Wiki 与养成规划、MaaEnd 远程控制。

| 功能 | 数据来源与使用条件 |
| --- | --- |
| 官网公告与活动日历 | 读取终末地官网的公告列表和全文；复用终末地公告解析规则。没有成功的官网快照时回退 B站官号内容；已有官网数据时保留原来源与日期。 |
| 寻访记录 | 鹰角通行证绑定的官服或 B 服角色与独立账本；增加官方记录页已使用的重构寻访类型。 |
| 个人档案 | 用鹰角通行证一键连接森空岛（或手动粘贴官方会话）、选择绑定角色后读取；显示账号、理智恢复、日常与通行证、干员、地区据点与收集、帝江号、成就。干员列表与详细配装使用两个官方接口，点击“查看配装”后按需读取技能、武器、基质与装备；未开放的详情会说明不可查。缺失值保留未知，不按零处理。 |
| 挑战记录 | 从森空岛读取战争回响、影拓丰碑、危机合约的结构化记录；尚未开放或不可见的内容显示上游状态。 |

| 蓝图收藏 | 手动保存蓝图名称、分享码和备注；支持修改、删除、复制及导出。只保存在本机，不扫描游戏内工厂，也不把分享码提交到外部网站。 |

鹰角与森空岛继续分别保存授权和原始资料。云端页面按同一个已验证游戏角色合并展示：账号列表提供本人角色的游戏编号，只有渠道、服务器和游戏角色编号一致，且双方配对唯一时，才在一个入口显示档案与寻访。旧响应只能通过确切的通行证父角色关系关联，不凭昵称配对。不同角色、未知渠道和存在歧义的授权保持分开。

合并页只需选择角色，无须切换资料来源；档案、干员、挑战和蓝图使用该角色的森空岛授权，寻访和逐抽记录使用鹰角授权。两个来源保留各自的更新时间和错误状态，单侧读取失败不覆盖另一侧的数据。切换角色或授权变化会取消两个来源的旧请求并清除旧视图；当前来源失效时，只能转到此前已确认关联且身份未改变的有效来源。账号设置仍可分别管理两项授权。

## 第一期报告与 QQ

网页新增干员名称搜索、稀有度/职业筛选和排序，地区按据点、派驻、调度券与收集差额分层，帝江号按舱室和驻守人员展示。总览待办仅覆盖已知的每日、每周总进度，不宣称已取得完整任务清单。帝江号采用注明来源的公开参考模型，将心情、信赖原始值换算为快照百分比与信赖阶段，网页与 QQ 使用相同精度。原值继续保留，缺失或超模型范围的心情显示未知；不按时间推算实时恢复。

配装详情作为独立内容层显示，返回列表保留筛选与排序；详情取得时间与账号档案时间分别显示，读取失败保留的旧详情会标记陈旧。列表用官网头像，详情优先用官网人物图，加载失败依次回退头像和文字。地区名称优先采用当前档案，已知 ID 可补标签；确认空派驻显示“无派驻”，未采集状态保持未知。

网页与 QQ 配装补充可选战术道具名称、稀有度、图标及主动/被动效果，兼容直接对象与 `tacticalItemData` 包装；缺失不等于未装备，效果保留来源模板，不猜替换参数。真实接口已确认干员对象的 `ownTs`，解析为可选 `obtained_at` 并显示北京时间；缺失或非法值保持未知，不从奖章日期或抓取时间回填。网页使用选中干员的独立详情，QQ基础资料使用档案快照，分别保留各自来源时间。

“光荣之路”展示完整已返回勋章列表，区分来源声明数量与已返回数量，显示已有名称、分类、等级、镀层和获得时间；网页支持分类筛选、名称搜索与日期排序。缺分类的奖章仍然可见，缺字段保持未知，不按原站默认截断为十项。QQ 复用网页内容，保留当前快照的全部分类与明细；超过整张图片的安全上限时明确提示并回退文字，不裁剪后声称完整。

`parse_card` 在原兼容字段外附加 `report.schema_version = 1`，由 `endfield_reports.build_endfield_report` 整理。旧快照可重建报告；旧空数组不能证明成功采集，因此统计保持未知。抓取时间与游戏观测时间分别显示，缺失观测时间不拿抓取时间冒充。寻访账本附加 `report`，准确区间均抽只统计当前展示的准确出货区间，不能当作生涯均值；记录下限、缺口、免费抽和待续传状态仍保留。

寻访每个已知候选池记录扫描状态，尚未访问和预算中断不再误报完成；成功空池也计入扫描覆盖。旧记录无法证明已完整扫描时显示未知，迁移兼容旧五列和新增状态的六列池表。

概览增加独立的鹰角寻访摘要，显示已保存抽数、稀有度、免费记录、准确区间均值和同步状态。摘要与详情均核对当前鹰角角色；云端还核对授权与快照的账号/角色。森空岛授权不展示其他鹰角授权的账本，身份失效或不匹配时隐藏统计。每池明确最近6★历史的报告覆盖（新账本上限50条），更早的已保存逐抽记录仍可在网页查看或导出；四星与未知/其他稀有度分别计数。

挑战页和云端本人详情共用战争、丰碑、危机报告。各分类显示自己的抓取时间，保留赛季、轮换、关卡和已有荣誉；没有来源上限时不计算完成率。同一分类重读失败可显示原资料并标记待更新，切换分类或账号会清除旧视图。尚未采集、请求失败、成功空返回和明确不支持分别说明。

云端网页和 QQ 从本人同一账号快照消费报告。QQ 指令为 `终末地 总览`、`终末地 角色`、`终末地 角色 精确名称`、`终末地 探索`、`终末地 帝江号`、`终末地 光荣之路`（也可用“勋章”“奖章”）、`终末地 挑战`、`终末地 寻访战报`（理智、练度、地区指令已于 2026-10-21 下线）；默认只查缓存，主动发送 `终末地 刷新` 才使用既有刷新队列。详情只显示已采集配装，未采集与未装备分开说明。图片正常为一张完整长图，超出资源限制时明确提示并回退文字摘要。详细说明见 [QQ 指令](cloud-qq-interaction.md) 与 [公开素材](qq-public-assets.md)。

网页“查看配装”取得的独立详情可供 QQ 复用；只匹配同一账号、角色、授权 ID/版本和干员 ID 的现有内存缓存。基础练度仍来自账号档案，武器、装备、技能来自详情，各自保留抓取时间；旧详情或失败后保留的数据明确标记。QQ 不为此加载凭据或发起上游请求，服务重启后需在网页重新查看配装。

`终末地 挑战` 复用网页已查看的战争、丰碑与危机默认查询缓存，各类别独立标记时间与旧数据状态。没有成功缓存的类别提示去网页查看；空列表不推断未参与，单条或当前赛季不冒充完整历史。授权、角色与默认查询键必须一致，QQ 不创建会话或重新加载凭据；服务重启后需重新在网页查看相关类别。

挑战长图复用网页的三分类报告，保留各分类的状态、时间与当前已返回明细。大量战争记录不能通过额外模板预算挤掉丰碑与危机内容；整张超限时明确提示并回退文字，可到网页查看。

QQ寻访按池分组展示统计与当前报告已经返回的全部明细，不额外限制池数或截取各池首屏；网页账本原有的历史窗口与分页不等于完整生涯记录。均抽始终使用报告中的准确区间，不随图片布局重算。整张超限时明确提示并回退文字摘要。干员详情会显示已经采集的技能专精。地区调度券兼容来源的`count`与旧拼写`conut`，正常字段优先且零值有效；派驻干员兼容已观察到的单ID与数组形状。

本地的一键连接保留；云端账号通过已有本人授权与父子授权联动管理，不调用本地全局会话接口。PR #12 的历史测试和 Pillow 验图仅代表该分支当时的实现；本次合并改用现有共用 Vue/Chromium 长图入口，其回归、实际部署与群内收图分别记录，不能把旧分支的合成证据当作合并后验收。历史证据见 [看板迭代验收](superpowers/plans/2026-10-15-endfield-dashboard-refinement.md)。

## 连接森空岛

已在「社区账号」登录鹰角通行证时，在终末地“概览”点击「用鹰角通行证连接」：程序用已保存的通行证令牌向鹰角申请森空岛授权码（appCode `4ca99fa6b56cc2ba`，type 0），再换取森空岛会话，全程不带设备标识，并自动选中与通行证登录相同的角色；绑定中没有同一角色时不自动选择。程序不生成替代设备指纹，也不调用第三方转发服务。

换取被拒或未登录通行证时，使用「手动连接（备用）」：填入自己已登录的官方森空岛网页会话凭据；若官方要求设备信息，可填入同一官方会话的原生设备标识。连接验证成功后，选择返回的终末地角色再读取档案。

由通行证换来的会话跟随通行证登录：退出或切换鹰角通行证账号时一并清除；会话过期时自动用通行证重新换取一次，并保留所选角色。手动连接的会话与通行证互相独立。断开后不会自动重连。每次换取都会在森空岛新建一个会话，但不会使浏览器等处已有的会话失效（2026-10-14 实测）。

会话凭据通过现有 `CredentialStore` 加密，保存在数据库旁的 `*.endfield-skland.credentials.json`；Windows 使用当前用户的 DPAPI，其他系统沿用项目现有本机加密方式。短期签名令牌只在内存中使用；通行证令牌只保存在社区账号的凭据文件中，不写入此文件。页面状态、日志、蓝图与抽卡导出均不包含凭据。请不要把任何凭据贴进问题反馈或拉取请求。

手动连接的会话过期或平台设备校验拒绝时，需要重新连接自己的官方会话；通行证令牌失效时，需在「社区账号」重新登录。程序不承诺此类内部接口长期不变。森空岛返回成功且身份与所选角色一致后才更新档案；失败保留本次运行中已取得的数据并标记陈旧。

## 日期、刷新与存储

- 官网公告、地图目录与点位缓存保存在 `*.endfield-public.sqlite3`，按需读取，主动刷新可更新公告。网络或格式异常保留上次成功缓存并说明失败。
- 官网 `NEWS` / `EVENTS` 接入原调度器与活动提醒；只有明确、带时区的截止时间参与临期提醒。
- “版本更新后”保持相对开始；“版本更新维护前”只有在后续维护公告发布后才补上时间；“于三次寻访后结束”等文字不猜测日期。
- 官方寻访页现明确说明可查近 90 日且约有 30 分钟延迟。本地账本长期保存已同步记录；超出官方窗口且本地从未保存的历史无法补回。
- 重构寻访使用独立类型 `E_CharacterGachaPoolType_Rerun`，与特许寻访分开统计。其他新类型仍需按官方页面更新。
- 蓝图收藏存于 `*.endfield-blueprints.sqlite3`，与任何游戏账号退出操作无关。支持导出备份，单机最多 1000 条。

## 验证范围

2026-09-28 已实际读取官网公告与全文、官方地图目录、类别和区域点位，并核对官方寻访页脚本中的重构寻访枚举及 90 日说明。测试使用固定样例验证解析、失败保留、日期规则、账号隔离、请求签名、蓝图保存导出和页面交互。

2026-10-14 用官服真实账号验证：鹰角短信登录（未触发人机验证）、寻访同步；手动连接和通行证换取的森空岛会话都能读取档案、签到日历与记录、图鉴和挑战记录，且不需要设备标识。样本只有一个账号，服务端若改为按条件要求设备信息，一键连接会提示改用手动连接。签到写入尚未用真实账号验证。测试通过表示实现行为经过检查，不表示任意账号、渠道服或所有版本的上游接口已经实测。B服与国际服的独立登录流程不在本次接入范围内；完整背包、邮件、全部任务明细和个人设施地图没有作为已实现功能发布。
