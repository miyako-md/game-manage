## 来源边界

1. 烟云赠礼只写“3.6版本更新后”。维护预计结束时刻不等于实际开服时刻，不能静默填成00:00或11:00；应保留原文、相对时间及依赖版本，页面显示“更新后”。
2. 总公告提到角色与武器，但没有给出全部唤取时段。独立公告[身赴三途](https://t.bilibili.com/1245903013291229191)给出9月10日10:00—9月29日11:59；[仙风玉影水天清](https://t.bilibili.com/1238110224628318212)给出版本更新后—9月10日09:59。覆盖卡池需结合这些独立通知。
3. 独立唤取公告把“活动时间”与日期放在相邻两行；当前解析器只读取含“活动时间”的同一行，直接复用会得到空日期，需要分段适配。
4. 窗口内已有3.7前瞻宣传。选择公告必须核对当前版本，不能只按最新发布时间；维护补偿、永久剧情开放、历史版本活动也须区分。
